## V8代码优化
### 隐藏类，Hidden Class
JavaScript是一种动态编程语言，这意味着在对象实例化后可以很容易地从对象中添加或删除属性。例如，在下面的代码片段中，对象是用属性“make”和“model”实例化的；但是，在对象已经创建之后，又动态添加“year”属性。

``` javascript
var car = function(make,model) {
    this.make = make;
    this.model = model;
}
var myCar = new car(honda,accord);
myCar.year = 2005;
```
大多数JavaScript解释器使用了类似字典的对象（基于散列函数）存储对象属性值的内存位置，这种结构使得在JavaScript中检索属性值的计算成本比在Java等非动态编程语言中要高。在Java中，对象的所有属性在编译前由固定的对象布局决定，不能在运行时动态添加/删除。因此，属性的值（或指向这些属性的指针）可以作为连续缓冲区存储在内存中，每个值之间有固定的偏移量。偏移量的长度可以很容易地根据属性的类型来确定，而这在JavaScript中是不可能的，因为属性的类型可以在运行时改变。
在像Java这样的非动态语言中，通常只需要一条指令就可以确定属性在内存中的位置，而在JavaScript中，需要多条指令才能从哈希表中检索位置。因此，JavaScript中的属性查找要比其他语言慢得多。 —— 这句话不是很理解

由于使用字典在内存中查找对象属性的位置效率非常低，V8使用了一种不同的方法：隐藏类。隐藏类的工作原理类似于Java等语言中使用的固定对象布局（类），区别是JavaScript中对象的隐藏类是在运行时创建的。在阅读本文的其余部分时，请记住V8为每个对象附加了一个隐藏类，隐藏类的目的是优化属性访问时间。现在，让我们来看看它们到底是什么样子。
``` javascript
function Point(x,y) {
  // 刚开始运行创建第一个隐藏类 c1
  this.x = x; // 创建第二个隐藏类 c2
  this.y = y; // 创建第三个隐藏类 c3
}
var obj = new Point(1,2);
```

``` javascript
function Point(x,y) {
  this.x = x;
  this.y = y;
}

var obj1 = new Point(1,2);
var obj2 = new Point(3,4);
// 此时 obj1 obj2 两个对象隐藏类相同
obj1.a = 5;
obj1.b = 10;

obj2.b = 10;
obj2.a = 5;
// 由于赋值顺序不同。此时 obj1 obj2 两个对象隐藏类相同
```
Class transition（类过渡）在 V8 中指的是在对象属性的变化中，从一个隐藏类（Hidden Class）转变为另一个隐藏类的过程。当一个对象的属性发生变化时，V8 会更新该对象的隐藏类，以反映属性的变化。这种从一个隐藏类到另一个隐藏类的转变被称为类过渡。

### 内联缓存，Inline Cache
V8利用了另一种常用的优化动态类型语言的技术，称为“内联缓存”（Inline Cache）。内联缓存的基本假设是重复调用 __同一方法往往会发生在相同类型的对象__ 上。

内联缓存的实现方式很简单：首先，V8引擎会对高频函数调用进行缓存。当函数被再次调用时，V8引擎会检查缓存并直接使用已经生成的机器码，而不是再次进行动态分派。这样的做法可以大大减少函数调用的时间开销，显著提升JavaScript代码的执行效率。

每当在特定对象上调用方法时，V8引擎必须执行一次隐藏类的查找，以确定访问特定属性的偏移量。在对同一隐藏类的两次成功方法调用后，V8会跳过隐藏类的查找，并简单地将属性偏移量添加到对象指针本身。对于将来的所有调用， __V8引擎都假设隐藏类没有改变，并使用之前查找过程中存储的偏移量直接跳转到特定属性的内存地址__ ，从而大大提高了执行速度。
