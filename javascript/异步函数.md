## Promise和async
### Promise
#### Promise 基础状态

Promise 有且只有三个状态 pending resolved(浏览器中一般叫做 fulfilled) rejected\
状态是私有的，不能通过JavaScript修改\
__pending__是Promise的初始状态。
``` javascript
const p1 = new Promise((resolve, reject) => {
  setTimeout(() => {
  }, 500)
})
console.log(p1) // Promise {<pending>}
setTimeout(() => {
    console.log(p1) // Promise {<pending>}
}, 1000)

const p2 = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve(1)
  }, 500)
})
console.log(p2) // Promise {<pending>}
setTimeout(() => {
    console.log(p2) // Promise {<fulfilled>: 1}
}, 1000)

const p3 = new Promise((resolve, reject) => {
  setTimeout(() => {
    reject(2)
  }, 500)
})
console.log(p3) // Promise {<pending>}
setTimeout(() => {
    console.log(p3) // Promise {<rejected>: 2}
}, 1000)
```
状态不可撤销，不可修改。一旦 resolve() 或者 reject() 被调用，状态都不可撤销。继续修改会静默失败
``` javascript
const p1 = new Promise((resolve, reject) => {
  resolve(1)
  reject(2)
})
console.log(p1) // Promise {<fulfilled>: 1}
setTimeout(() => {
    console.log(p1) // Promise {<fulfilled>: 1}
}, 1000)
```
#### Promise.resolve 和 Promise.rejected
Promise 并非一开始就必须处于 pending 状态\
可以通过以上，直接定义定义一个确定状态的Promise\
函数支持一个参数，用来传递 解决值或拒绝理由

``` javascript
const p1 = Promise.resolve(1)
const p2 = Promise.reject(2)
console.log(p1) // Promise {<fulfilled>: 1}
console.log(p2) // Promise {<rejected>: 2}
```
#### Promise 实例方法
__1. Thenable__ \
   ECMAScript 暴漏的所有异步结构中，任何对象都有一个then()方法。这个方法并认为是实现了Thenable接口
``` javascript
class TestTheable {
  then() {}
}
```
__2. Promise.prototype.then()__ \
   函数接受两个函数。onResolved 和 onRejected。两个函数都是可选的，如果提供，会分别在进入 fulfill 和 rejected 状态时执行
``` javascript
const p1 = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve(1)
  }, 1000)
})
const p2 = new Promise((resolve, reject) => {
  setTimeout(() => {
    reject(2)
  }, 1000)
})
function onResolved(e) {
  console.log('onResolved', e)
}
function onRejected(e) {
  console.log('onRejected', e)
}
p1.then(onResolved, onRejected) // onResolved 1
p2.then(res => onResolved(res), res => onRejected(res)) // onRejected 2
```
非函数处理会被忽略、不推荐
``` javascript
p1.then("onResolved", onRejected) // 不推荐
p2.then(null, res => onRejected(res)) // 推荐
```
__3. then 返回的是一个新的 Promise 实例__
``` javascript
const p1 = new Promise((resolve, reject) => {})
const p2 = p1.then(null, null)
console.log(p1) // Promise {<pending>}
console.log(p2) // Promise {<pending>}
console.log(p1 === p2) // false

const p3 = Promise.resolve(1)
const p4 = p1.then(null, null)
console.log(p3) // Promise {<fulfilled>: 1}
console.log(p4) // Promise {<pending>}
console.log(p3 === p4) // false
```
这个新的 Promise 基于 onResovled 返回值创建。没有提供处理程序时，包装 undefined \
返回为Promise 会直接放回
抛出异常时，会默认返回 rejected

``` javascript
const p1 = Promise.resolve(1)
const p2 = p1.then(null, null)
const p3 = p1.then(() => 2, () => 2)
const p4 = p1.then(() => p3, () => p3)
const p5 = p1.then(() => Promise.reject(3), () => Promise.reject(3))
const p6 = p1.then(() => { throw 4}, () => { throw 4})
setTimeout(() => {
  console.log(p2) // Promise {<fulfilled>: 1}
  console.log(p3) // Promise {<fulfilled>: 2}
  console.log(p4) // Promise {<fulfilled>: 2}
  console.log(p5) // Promise {<rejected>: 3}
  console.log(p6) // Promise {<rejected>: 4}
}, 0)
```
__onRejected返回的普通值也会被Promise.resolve()包装__。因为拒绝处理程序在捕获错误后，不继续抛出异常是符合预期的行为。
``` javascript
const p1 = Promise.reject(1)
const p2 = p1.then(null, null)
const p3 = p1.then(() => 2, () => 2)
const p4 = p1.then(() => p3, () => p3)
const p5 = p1.then(() => Promise.reject(3), () => Promise.reject(3))
const p6 = p1.then(() => { throw 4}, () => { throw 4})
setTimeout(() => {
  console.log(p2) // Promise {<rejected>: 1}
  console.log(p3) // Promise {<fulfilled>: 2}
  console.log(p4) // Promise {<fulfilled>: 2}
  console.log(p5) // Promise {<rejected>: 3}
  console.log(p6) // Promise {<rejected>: 4}
}, 0)
```
__4. catch 和 finally__
Promise.porototype.catch()用于给 Promise 添加拒绝处理程序。方法只接受 onRejected函数 一个参数。\相当于一个语法糖。等价于 Promise.prototype.then(null, onRejected)
``` javascript
const p = Promise.reject(1)
const onRejeced = function(e) {
  setTimeout(console.log, 0, 'onRejeced')
}
p.then(null, onRejeced) // onRejeced
p.catch(onRejeced) // onRejeced
```
catch 函数也会返回一个新的 Promise 对象，行为和 then 一致
``` javascript
const p1 = new Promise(() => {})
const p2 = p1.catch()
console.log(p1, p2, p1 === p2) // Promise {<pending>} Promise {<pending>} false
```
Promise.porototype.finally() 在 Promise 解决和拒绝状态时都会执行，本身不知道 Promise 的状态时解决还是拒绝，所以一般用于清理代码，防止代码冗余

#### Promise 取消 和 进度通知
ES6 不提供 Promise 取消方法，可以参考以下
``` javascript
class EndPromise {
  constructor(func) {
    this.Promise = new Promise((resolve, reject) => {
      
      func(() => {
        setTimeout(() => {
          console.log('end')
          resolve()
        }, 0)
      })
    })
  }
}

const startButton = document.querySelector('#start')
const endButton = document.querySelector('#end')

function end(delay) {
  return new Promise((resolve) => {
    const timer = setTimeout(() => {
      console.log('resolve')
      resolve()
    }, delay)
    const endPromise = new EndPromise((func) => {
      endButton.addEventListener('click', func)
    })
    endPromise.Promise.then(() => clearTimeout(timer))
  })
}
startButton.addEventListener('click', () => end(1000))
```
